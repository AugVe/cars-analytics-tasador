# 🚗 Cars Analytics: Tasador Inteligente

## Descripción
Sistema inteligente para la tasación y segmentación de vehículos mediante Machine Learning. La aplicación permite:
- **Tasar vehículos** en tiempo real basándose en características técnicas.
- **Detectar oportunidades (gangas)** comparando el precio de mercado con el precio publicado.

## Arquitectura
- **Frontend:** Streamlit Cloud.
- **Backend:** FastAPI desplegado en Render.
- **Modelos:** Scikit-learn (Clasificación, Regresión y Clustering).

## Tecnologías utilizadas
- Python 3.14
- Pandas / Joblib
- Streamlit / FastAPI
- Render (Cloud)

## Instalación
(Aquí puedes poner los comandos para correrlo localmente si alguien quiere clonar tu repo)
1. `pip install -r requirements.txt`
2. `uvicorn main:app --reload`
